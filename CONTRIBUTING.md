# Contributing to INCREMENT

Thank you for your interest in contributing to INCREMENT! We welcome contributions that improve the tool's functionality, performance, documentation, and usability.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/increment.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `npm install`
5. Start the development server: `npm start`

## Development Guidelines

### Code Style

- Follow the existing code style and conventions
- Use meaningful variable and function names
- Keep functions focused and modular
- Add comments for complex logic

### Testing

Before submitting a pull request:

1. Test your changes locally with `npm start`
2. Build the production version with `npm run build`
3. Verify the build completes without errors
4. Test your changes with different graph datasets if possible

### Commit Messages

- Use clear, descriptive commit messages
- Start with a verb in the present tense (e.g., "Add feature", "Fix bug", "Update documentation")
- Reference relevant issues when applicable

## Submitting Changes

1. Push your changes to your fork
2. Open a pull request against the main repository
3. Describe your changes clearly in the PR description
4. Link any related issues
5. Be responsive to feedback and review comments

## Reporting Issues

When reporting bugs or requesting features:

- Check if the issue already exists
- Provide a clear description of the problem or request
- Include steps to reproduce (for bugs)
- Describe the expected behavior
- Include screenshots or examples if helpful

## Areas for Contribution

We particularly welcome contributions in these areas:

- Performance optimizations for large graphs
- Additional visualization modes
- Enhanced filtering capabilities
- Better keyboard navigation
- Accessibility improvements
- Documentation and examples
- Test coverage
- Integration with other graph databases
